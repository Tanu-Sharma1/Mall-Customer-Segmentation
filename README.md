## Project Scope

The objective of this project is to segment mall customers into different groups based on their annual income and spending score using the K-Means Clustering algorithm. Customer segmentation helps businesses understand customer behavior and create targeted marketing strategies.

---

---

## Dataset

Mall Customers Dataset

Attributes:

- CustomerID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1-100)

1. Data Collection
2. Data Exploration
3. Feature Selection

5. K-Means Clustering
6. Cluster Visualization
7. Result Analysis

---

## Output

The project identified 5 customer segments:

- High Income, High Spending
- High Income, Low Spending
- Low Income, High Spending
- Low Income, Low Spending
- Average Customers
